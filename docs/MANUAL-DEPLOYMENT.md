# Publicação manual

Esta proposta prepara uma publicação manual das aplicações existentes, com revisão prévia e identificação do código utilizado. Testes e builds usam ferramentas convencionais na CI, sem modelos.

A integração Google ainda depende da configuração operacional privada. Nenhuma publicação é iniciada automaticamente por este PR.

Os procedimentos de autenticação, configuração e recuperação ficam na documentação privada do proprietário. O fluxo não inicia processamento de vídeos.
